# 🏎️ VICE HEARTS

**VICE HEARTS** is a simple, text-based console game written in Python. Players start with a set budget and can purchase luxury cars to build their personal garage. This project demonstrates fundamental Python concepts including Object-Oriented Programming (classes and objects), loops, conditionals, and lists.

## ✨ Features
* **Starting Balance:** Begin the game with `$5,000` in virtual cash.
* **Car Dealership:** Choose between buying a **Porsche (\$2,000)** or a **BMW (\$4,000)**.
* **Budget Validation:** Prevents purchases if you don't have enough money.
* **Personal Garage:** View all the cars you have collected at any time.
* **Interactive Menu:** Easy-to-use terminal menu loop.

## 🛠️ Technologies Used
* **Python 3**

## 🚀 How to Run the Game

1. **Clone the repository** (or download the code file):
   ```bash
   git clone https://github.com
   ```

2. **Navigate to the project directory:**
   ```bash
   cd YOUR-REPO-NAME
   ```

3. **Run the Python script:**
   ```bash
   python main.py
   ```
   *(Note: Replace `main.py` with whatever name you gave your Python file).*
